# Sugarbeet Raw Images

## Project
Sugarbeet Detection using YOLO and Hybrid Models

## Dataset
The project uses sugarbeet images and corresponding annotation
labels for object detection.

## Dataset Source
Original source URL: To be verified.

## Local Dataset Locations
- dataset_70_20_10
- dataset_70_20_10_detection
- dataset_80_10_10_detection
- dataset_detection

These folders contain prepared datasets for different experiments.
They are not necessarily the original raw dataset.

## Split Configurations
- Split Ratio 1: 70% training, 20% validation, 10% testing.
- Split Ratio 2: 80% training, 10% validation, 10% testing.

## Notes
The prepared datasets remain in the main project directory.
Refer to the relevant YAML configuration files for dataset paths.

The original dataset source and redistribution permissions
must be verified before distributing raw images.
