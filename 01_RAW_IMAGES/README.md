# Sugarbeet Raw Images

## Project
Sugarbeet Detection using YOLO and Hybrid Models.

## Dataset Description
This folder is intended to document the original sugarbeet image dataset used for object detection and model experiments.

The dataset contains sugarbeet images and their corresponding annotation labels.

## Dataset Usage
The prepared datasets for the 70:20:10 and 80:10:10 train-validation-test splits are maintained separately in the project workspace.

The `01_RAW_IMAGES` folder documents the raw dataset location and source. The original raw images should be uploaded here only after confirming the source files and redistribution permissions.

## Notes
- Prepared datasets are not necessarily identical to the original raw dataset.
- Refer to the project documentation for model configurations and evaluation results.
- Verify the original dataset source and licensing before sharing the images.
