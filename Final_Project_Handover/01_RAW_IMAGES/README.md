# Sugar Beet Raw Images

## Project
Sugar Beet Detection Using YOLO and Hybrid Models

## Dataset
The project uses sugar beet images organized into training,
validation, and test splits for object detection.

## Local Dataset
Prepared images are available in:
- dataset_70_20_10/
- dataset_80_10_10/
- dataset_detection/
- dataset_80_10_10_detection/

These are prepared datasets, not confirmed original raw archives.

## Original Dataset Source
Potential source: University of Bonn Sugar Beets 2016 dataset
https://www.ipb.uni-bonn.de/data/sugarbeets2016/

The exact source and applicable license must be verified.
